  authors for the last 120 days, deploy keys, webhooks, Actions secrets.
- `osv-scanner scan source -r .` found `certifi` 2026.6.17 (critical).
- `gitleaks git .` and `gitleaks dir .`: no leaks.
- `zizmor .github/workflows` flagged the unpinned actions in
  `dependency-review.yml`. `actionlint` had no errors on that file.
- `uv lock --upgrade-package certifi==2026.10.19`, then `uv sync --locked` and
  `uv run pytest -q`.

## Decisions

- Lowest fixed version of `certifi`, even though it is inside the 7-day
  cooldown: there is no older fixed release.
- `dependency-review-action` stays on v4 (pinned to v4.9.0) instead of moving
  to v5.
- `phase1/agent.py` `fetch_url`: first left as is (fixed prompt, local demo).
  CodeRabbit flagged it on the PR. Its claim that `main()` takes any task is
  wrong, but a fetched page can still steer the model to an internal URL, so
  it is fixed: public http(s) hosts only, no automatic redirects. DNS can
  still change between the check and the request; the code comment says so.
