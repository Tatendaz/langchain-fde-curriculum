# Feature: Security sweep, October 2026

**Branch:** security/sweep-2026-10-25
**Date:** 2026-10-25

## Summary

Bumps `certifi` from 2026.6.17 to 2026.10.19 in `uv.lock`, and pins the two
actions in `dependency-review.yml` to full commit SHAs.

## Motivation

- `certifi` 2026.6.17 ships emSign root CAs whose intermediate CA keys were
  compromised (GHSA-6q48-6c7w-9gw2, PYSEC-2026-4320, CVSS 9.1). Anyone holding
  those keys can issue certificates that `httpx` trusts. 2026.10.19 is the
  first fixed version named in the advisory.
- `dependency-review.yml` was the only workflow still using mutable tags
  (`actions/checkout@v5`, `actions/dependency-review-action@v4`) and the only
  one that left the checkout token on disk.

## What changed

- `uv.lock`: `certifi` 2026.6.17 -> 2026.10.19. No other package moved.
- `.github/workflows/dependency-review.yml`: `actions/checkout` pinned to the
  same v7.0.1 SHA the other workflows use, with `persist-credentials: false`;
  `actions/dependency-review-action` pinned to the v4.9.0 SHA (what `v4`
  pointed to).

## Notes

- 2026.10.19 is newer than the sweep's 7-day cooldown. It is the lowest fixed
  version, so it was taken on purpose. 2026.10.18 is not fixed.
- Made with `uv lock --upgrade-package certifi==2026.10.19`, not a full
  upgrade.
