# Security sweep 2026-10-31: langgraph SDK streaming advisory

**Branch:** security/routine-2026-10-31
**Date:** 2026-10-31

## Summary
Moves `langgraph` from 1.2.5 to 1.2.14 and `langgraph-sdk` from 0.4.4 to 0.4.6 in `uv.lock`.

## Motivation
GHSA-3fx2-cqw9-xr3c / CVE-2026-118667 (moderate, published 2026-10-28). Unencoded
attacker-controlled `thread_id` or `assistant_id` values in LangGraph SDK v3 streaming can
redirect an authenticated GET request to another path on the same server. Affects
`langgraph-sdk` 0.4.0 to 0.4.5 and `langgraph` 1.2.3 to 1.2.13.

## What changed
- `uv.lock`: those two packages only. `pyproject.toml` is unchanged (`langgraph>=1.0,<2`).

## Notes
- Both versions were published 2026-10-06, outside the 7-day cooldown. They are the lowest
  fixed versions.
